Python: 3.10 (recomandat)
Biblioteci: opencv-python, numpy, matplotlib
Instalare: pip install -r requirements.txt

Structură fișiere
    Cod principal: main_code.py
    Configurații: parameters.py
    Procesare imagini: image_processing.py, ocr_processing.py, tile_detection.py
    Rezultate: folder fisiere_solutie/

Rulare
Pregătiți imaginile de intrare în folderul definit în parameters.py.
Rulați:
python main_code.py
Rezultatele vor fi salvate în fisiere_solutie/.
